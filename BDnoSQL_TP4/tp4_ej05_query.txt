Ejercicio 5 - Tipos de especialidad con sus especialidades asociadas

Colección: participaciones (cargada con tp4_ej05.py). Un documento por fila del archivo, es
decir, una participación completa:
{ _id (automático),
  deportista:   { id, nombre, fecha_nacimiento, pais: { id, nombre } },
  especialidad: { id, nombre, tipo: { id, nombre } },
  torneo:       { id, nombre, ciudad: { id, nombre }, pais: { id, nombre } },
  intento, marca }

La query usa dos $group seguidos:
1. Por tipo y especialidad: cada especialidad aparece miles de veces y acá queda una sola
   (de 161.403 documentos a 20). $first guarda los nombres, que son iguales en todo el grupo.
2. Por tipo: $push junta los nombres de sus especialidades en una lista. Entran los 20
   documentos del paso anterior y salen 4, uno por tipo, sin repetidos.
Al final, $project muestra id_tipo, nombre_tipo y especialidades. No se ordena porque la
consigna no lo pide.

Resultado: se obtuvo en Robo3T agregando .forEach(printjsononeline) al final de la query,
que imprime un documento por línea. Con 4 documentos no hacía falta (entran en una
página de Robo3T), pero se usó en todos los ejercicios para mantener el mismo formato.

Query:
db.participaciones.aggregate([
    {$group: {
        _id: {id_tipo: "$especialidad.tipo.id", id_especialidad: "$especialidad.id"},
        nombre_tipo: {$first: "$especialidad.tipo.nombre"},
        nombre_especialidad: {$first: "$especialidad.nombre"}
    }},
    {$group: {
        _id: "$_id.id_tipo",
        nombre_tipo: {$first: "$nombre_tipo"},
        especialidades: {$push: "$nombre_especialidad"}
    }},
    {$project: {_id: 0, id_tipo: "$_id", nombre_tipo: "$nombre_tipo", especialidades: "$especialidades"}}
]);
